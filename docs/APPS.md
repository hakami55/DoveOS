## Open and connect

- **Moonlight:** connect to your local network, add your PC, pair it, load its apps
  and start streaming. The PC needs a compatible streaming host.
- **DoveDeX:** authorize USB debugging on your Android device. Open USB directly,
  or set up Wi-Fi through USB, check the saved address, then open USB / Wi-Fi.
- **DoveAir:** put both devices on the same network, start the receiver and
  select it from the iPhone's Screen Mirroring panel.
- **DovePlayer:** open a supported media file from the USB drive.

Use your own accounts, network settings and pairings. A first release is called
final only after its installation and core application checklist passes.
